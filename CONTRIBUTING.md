# Contributing

Bug reports, documentation corrections, and reproducibility reports are welcome through GitHub Issues.

To propose a code change:

1. Create a branch from `main`.
2. Keep frozen Study I artifacts and published result files unchanged.
3. Add or update tests for behavioral changes.
4. Run the verification commands documented in `README.md`.
5. Open a pull request describing the scientific and software impact.

Do not commit downloaded OpenML feature or label data, credentials, access tokens, local caches, or personally identifying dataset records. Changes that alter a frozen protocol or result must be released as a new version and clearly labeled as prospective or post hoc.
