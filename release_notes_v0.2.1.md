# DataFaultBench v0.2.1

DOI-archival release accompanying *DataFaultBench: Selection Stability and Cross-Domain Transport of Data-Fault Interactions*.

This release preserves the verified scientific content of v0.2.0 while updating the software version and archival metadata for the Zenodo–GitHub integration.

Highlights:

- Frozen 55-domain manifest, Study I verification metadata, and reusable execution/analysis code.
- Source-isolated calibration and one-shot final confirmation records.
- Post hoc cross-fitting and component-transfer diagnostics.
- Reproducibly generated 90-scenario simulation with 180,000 repetitions and a zero-failure ledger in the release asset.
- Reusable Python package, automated tests, figures, machine-readable outputs, and integrity receipts.

Scientific status: the final source-disjoint directional test was not significant (`p = 0.131`). Cross-fitting and component decomposition are post hoc diagnostics. No external Study II outcome is included or claimed.
