# Data governance

DataFaultBench uses public OpenML benchmark tasks but does not broadly redistribute their raw feature and label values.

The release provides task identifiers, source-family review, provenance records, licence evidence where available, acquisition instructions, sanitation plans, hashes, and run receipts. Users must retrieve upstream tasks under the terms that apply at the time of access.

The 55-domain manifest and completed Study I artifact are frozen research records. Upstream changes, unavailable tasks, corrected metadata, or newly added domains must be documented as a new version rather than silently substituted into the published study.

Do not commit API credentials, tokens, local OpenML caches, unrestricted raw data, or personally identifying records.
